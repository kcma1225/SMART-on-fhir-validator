系統設定

Prism Database

設定外部 Prism proxy 的 PostgreSQL 連線字串。連線測試成功後，polling 才會開始抓取資料。

載入中

Prism Base URL

設定 Prism 系統的網址，Results 頁面的 Connection ID 將連結至 {baseUrl}/connections/{id}。

Polling

設定 validator 自動從 Prism database 抓取 connections 的排程。

抓取多久以前的封包（預設 24 = 最近一天）

危險區域

刪除資料庫內所有驗證結果紀錄，並立即重新抓取最近 24 小時的封包重新驗證（SMART 與 IUA）。此動作無法復原。
