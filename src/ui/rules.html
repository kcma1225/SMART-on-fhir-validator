欄位檢查規則

required

欄位不存在直接 FAIL，會讓該筆驗證失敗。

conditional

目前當 optional：有就 PASS，沒有 SKIP，不會 FAIL。

optional

欄位不存在記錄 SKIP；有就 PASS，不影響通過與否。

新增欄位

Flow：這個欄位屬於哪個驗證流程。範例：authorization_request

Field Name：要檢查的欄位名稱。範例：client_id

Location：欄位所在位置。範例：query_params、body_params、headers、response_body

Type：檢查類型。範例：required 缺少會 FAIL；conditional / optional 缺少會 SKIP。

Pattern：可選的正規表示式，用來檢查值格式。範例：^Bearer .+

Sort：同一 flow 裡的顯示排序，數字越小越前面。範例：0、10

編輯 Endpoint

Validator 會用 request URL 是否包含這段 path 來辨識 flow。
